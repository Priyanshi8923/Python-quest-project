# PYTHON QUEST GAME

A text-based Python quiz game with 5 levels.

## How to Run
1. Open terminal/command prompt
2. Go to project folder
3. Run: python main.py

## Features
- 5 Units: Basics, Data Types, Loops, Functions, File Handling
- Scoring system: 50 points on 1st try, 25 on 2nd try
- HUD shows Name, Score, Room

## Files
- main.py : Main game loop
- helpers.py : Common functions
- src/unit1.py to unit5.py : Level files
- docs/ : Documentation
